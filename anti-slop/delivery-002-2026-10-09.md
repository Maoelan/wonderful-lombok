# Anti-slop delivery gate 002

Design Read: halaman travel untuk wisatawan Lombok dengan dua kebutuhan utama, paket wisata dan transportasi, memakai bahasa visual editorial tropis. Dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- Hard Gate PASS: tidak ada em dash, klaim rekaan, testimonial rekaan, link internal mati, kontrol tanpa fungsi, atau copy teknis yang membingungkan pelanggan.
- Responsive PASS: struktur diperiksa pada desktop dan viewport 390 x 844; lebar dokumen 375 px tanpa horizontal overflow.
- Accessibility PASS: navigasi memakai link nyata, menu mobile memakai `aria-expanded`, form memakai label native, fokus terlihat, dan FAQ memakai `details` serta `summary`.
- States PASS: peta memiliki loading, empty, error, dan ready state; form memiliki validation dan success state.
- Purpose Gate PASS: gradient hanya menjaga kontras hero dan destinasi; emoji kendaraan berasal dari konten lama dan menjelaskan jenis layanan; tidak ada glow, glassmorphism, atau dekorasi tanpa fungsi.
- Liveliness PASS: focal point hero adalah pilihan kebutuhan, aksen emas dibatasi pada tindakan utama, dan motif hijau, krem, serif editorial konsisten.
- Content Structure PASS: alur sekarang bergerak dari pilihan kebutuhan ke paket atau transportasi, lalu konteks kepercayaan dan FAQ.
- Preserved Content PASS: paket, destinasi, rental kendaraan, travel bandara, alasan memilih layanan, FAQ, dan kontak dari website statis dipertahankan.
- Functional PASS: menu mobile membuka, FAQ membuka, kalkulator tetap berjalan, dan seluruh URL WhatsApp berisi konteks layanan.
- Console PASS: pemeriksaan browser tidak menemukan error atau warning.
- Build PASS: `npm test` menjalankan dua test dan `npm run build` selesai tanpa error.
